## 1. Definition of Workflow

| Колонка     | Картка потрапляє сюди, коли                                       | Картка виходить звідси, коли                                                                      |
| ----------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Backlog     | Є ключ, опис результату й тип роботи.                             | Зрозумілий критерій завершення, доступні вхідні матеріали, перевірено залежності.                 |
| Ready       | Картка підготовлена й має розмір приблизно одного-двох днів.      | Почато роботу і є вільне місце в In Progress.                                                     |
| In Progress | Зафіксовано старт і відкрито матеріал, який потрібно підготувати. | Результат доступний для перевірки й є місце в Review.                                             |
| Review      | Є файл, посилання або інший результат, доступний для звірки.      | Результат перевірено за умовою картки. За зауважень повернути в In Progress з урахуванням ліміту. |
| Done        | Перевірку пройдено, результат збережено, зафіксовано завершення.  | Повторне відкриття оформлюється із зазначенням причини.                                           |

## 2. WIP-ліміти

| Колонка     | Стартовий ліміт | Обґрунтування                                                                                             |
| ----------- | --------------: | --------------------------------------------------------------------------------------------------------- |
| In Progress |               2 | Початкова межа експерименту ЛР04. Дає місце для короткої задачі, коли інша потребує зовнішньої відповіді. |
| Review      |               1 | Перевіряється один результат за раз, щоб зменшити чергу готових матеріалів.                               |

Для навчальних карток F-xxx діє стартовий ліміт цього експерименту. Для історій продукту S-xx діють правила ЛР02: In Progress — 1, Review/QA — 1. На дошці навчальні картки й історії спринту мають окремі подання.

За вичерпаного ліміту наступна картка чекає в Ready. Спершу завершити поточну або усунути блокер. Заблоковані картки в роботі враховуються у WIP.

**Коли ліміт спрацював:** 2026-11-12, F-004 чекала в Ready через зайняте місце в In Progress; замість її старту завершено поточну роботу F-003.

## 6. Перший вимір

| Показник                     | Значення |
| ---------------------------- | -------: |
| Найкоротший cycle time, днів |          |
| Найдовший cycle time, днів   |          |
| Середній cycle time, днів    |          |
| Завершених карток у вимірі   |          |

Cycle time = дата завершення − дата старту. Початок і завершення одного дня дають 0. Вузьке місце та висновок записуються за історією переходів і спостереженнями. Ціль виміру — щонайменше 8 завершених карток.
